# Football League Dashboard

A Python web app that fetches live football data across multiple leagues and displays interactive stats and standings.

## Features
- Multi-league support (Premier League, Champions League, La Liga, Bundesliga, Serie A, Ligue 1, Eredivisie)
- Live standings with club crests
- Top scorers
- Best attack and defense
- Fun stats (most wins, best goal difference, most efficient team)

## Tech Stack
- Python
- Pandas
- Streamlit
- football-data.org REST API

## How to Run
pip install requests pandas streamlit
streamlit run app.py

## API
